# Setup & Installation

# bash
# Create virtual environment
python3 -m venv venv

# Activate it
source venv/bin/activate

# Install dependencies
pip install scapy colorama

# Run (root required for packet capture)
sudo venv/bin/python analyser.py
```

> **Note:** `sudo venv/bin/python` is required because Scapy needs root
> privileges to access the network interface. Running `sudo python` alone
> won't work as it bypasses the virtual environment.
